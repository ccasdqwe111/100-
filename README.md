# 100%绿色源代码 – 全聚合网址导航便民查询工具

源码获取：ym7k.com/19725/

这套是轻量化绿色网址导航 + 便民查询聚合系统，无加密、无后门、无暗链，源码纯净可直接部署二开，主打便民工具聚合、网址分类导航，适合本地门户、个人导航站、社群工具箱、站长引流站，PHP 单页版 / ThinkPHP 版本居多，部署简单、服务器资源占用低。

## ✅ 技术说明

-后端：PHP（极简版单文件 PHP / ThinkPHP），兼容 PHP5.6~PHP8.1，MySQL 可选（轻量版支持 sqlite 免数据库）
- 前端：原生 HTML+CSS+JS，自适应移动端 + PC 端，可自定义 UI 配色、主题
- 安全标注：宣传标注**100% 绿色源码**，无加密、无隐藏跳转、无恶意后门、无弹窗木马、不偷偷挂广告、无付费加密组件
- 部署：虚拟主机、轻量云服务器均可，上传直接运行，傻瓜式安装

## ✅ 核心功能：网址导航模块

1. 分类网址收录：自定义分类，综合搜索、影视、工具、学习、资源、本地服务、办公、AI 工具、短视频等
2. 站点卡片展示、图标 + 名称 + 简介，支持星级标记、置顶推荐
3. 搜索框聚合：百度、搜狗、必应、抖音搜索、AI 搜索多引擎一键切换
4. 自定义快捷书签，访客可添加自己收藏网址（可选开关）
5. 换肤功能：深色模式 / 浅色模式，自定义背景图
6. 轮播公告、首页公告弹窗、友情链接管理

## ✅ 便民聚合查询工具箱（核心亮点）

内置大量在线便民小工具，一键集成，不用单独对接复杂接口：

- 生活类：天气预报、快递查询、手机号归属地、IP 查询、万年历黄历、吉凶日历、汇率换算、单位换算
- 办公类：JSON 格式化、二维码生成、图片压缩、MD5 加密、时间戳转换、大小写转换、字数统计
- 本地便民：公交查询、油价查询、违章查询入口、地图跳转
- 娱乐辅助：短链接生成、随机抽签、密码生成器
- AI 聚合入口：跳转各类 AI 绘图、数字人、大模型站点（可自由增删）

> 
> 工具大多前端本地计算，少量调用公开免费接口，接口可后台替换

## ✅ 后台管理功能

1. 导航站点管理：新增、编辑、删除网址，分类排序、置顶设置
2. 工具箱管理：开启 / 关闭任意查询工具，自定义工具名称、跳转地址
3. 广告管理：自定义首页广告（可选，不强制内置广告）
4. 公告设置、SEO 配置：title、关键词、描述，适合做搜索引擎收录
5. 权限管理：管理员账号密码，日志查看
6. 缓存清理，一键备份数据
